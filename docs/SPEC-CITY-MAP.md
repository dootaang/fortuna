# 도시 노선도와 장면 (RP 화면) 설계

> 상태: 2판 1~4단계 구현 완료 (2026-10-15). 걷는 지도는 걷어 냈다. 만든 것과 설계가 다른 곳은 12절에 적었다.
> 1판(도트 JRPG 걷는 지도)은 1단계까지 만들어 배포했지만 방향을 바꿨다(11절).

디스코드에서 하던 RP 전체를 이 웹앱으로 옮긴다. 디스코드와는 연동하지 않는다.
도시는 **지하철 노선도**로 보고, 역(장소)을 누르면 그 **장면**으로 들어간다. 장면은 배경 카드 한 장 + 그곳에 있는 사람들 + 넓은 채팅이다.
이야기는 글로 진행하고, 그림은 분위기만 깐다. 새 사건이 생겨도 그림이나 연출을 새로 만들 필요가 없게 하는 것이 목표다.

## 0. 확정된 결정

| # | 질문 | 결정 |
|---|---|---|
| 1 | RP를 어디서 하나 | 전부 웹앱. 디스코드 연동 없음. 알림 없음 |
| 2 | 도시를 어떻게 보여 주나 | 종착역 노선도. 역을 누르면 바로 그 장소로 간다(걷기 없음) |
| 3 | 장소 안 | 배경 카드 + 여기 있는 사람 초상 + 넓은 채팅 (비주얼노벨식) |
| 4 | 배경 그림 | 모든 장소를 아르데코 카드형으로 통일. 휠 광장도 같다 |
| 5 | 딜러 이미지 | 딜러가 올린 이미지를 카드 맨 아래층에 깔고, 통일 필터와 틀을 위에 씌운다 |
| 6 | 통일 필터 기본값 | 은은하게. 이미지마다 강하게 / 은은하게 / 틀만 중에서 고른다 |
| 7 | 장소별 여러 장 | 한 장소에 이미지를 여러 장 올려 두고 세션 중에 바꿔 끼운다 (낮·밤, 평소·사건) |
| 8 | NPC 초상 | 딜러가 이미지로 올린다. NPC로 말할 때 같은 틀로 뜬다 |
| 9 | 채팅 장면 컷 | 딜러가 채팅에 그림 한 장을 띄운다. 나중 단계(10절 4단계) |
| 10 | 연출 | 미리 만든 효과 몇 가지(흔들림, 경보, 정전, 비, 안개)를 딜러가 켜고 끈다. 사건마다 새로 만들지 않는다 |
| 11 | 채팅 | 장소별 + 전체 + 귓속말 + 딜러 공지·NPC 발언. 마크다운, 행동, 봉인된 주사위. 기록은 남긴다 |
| 12 | 기존 기능 | 채팅 안에서 특기 결제, 봉인된 주사위, 기존 화면 바로 가기 |
| 13 | 기존 메뉴 | 그대로 둔다. 하단 메뉴 "도시"가 노선도로 들어간다 |

## 1. 화면 흐름

```
[도시] ──▶ ① 노선도 ──(역 누르기)──▶ ② 장면 ──(노선도 버튼)──▶ ① 노선도
```

- 처음 들어오면 캐릭터 초상을 만든다(6절). 그다음부터는 마지막에 있던 장면으로 바로 들어간다.
- 장면 화면 위쪽의 "노선도" 버튼으로 언제든 노선도로 돌아간다.

## 2. ① 노선도

포르투나는 기차를 타고 와서 내리는 종착역 도시다. 도시 지도를 지하철 노선도로 그린다.

```
                 탑 로비
         길드로 ●  ●
  한빛특구선 ━━━━●━━━━━━━━━┓          로엔하임선
                불야동      ┃      ┏━━●━━━●━━● 마왕성
                          ┃      ┃  성문광장 칼드록
   섹터9선 ━●━━●━━━━━━━━━━━ ◉ 휠 광장 (종착역)
       다운링크 글리치로       ┃ ┃ ┃
                     판돈로 ● ● ● 환전가 …
                       하우스 ●
```

- **한가운데 휠 광장이 종착역**이고, 일곱 구역이 노선 일곱 개로 뻗는다. 노선 색은 구역 색이다.
- 역 = 장소. 구역마다 바깥 장소 하나 + 안쪽 장소 2~4개 (아래 표). 모두 30곳 안팎.
- **역 표시**
  - 지금 거기 있는 사람: 초상 점 (●●)
  - 새 글: 금색 점. 마지막으로 본 뒤 올라온 글이 있으면 뜬다
  - 아직 가 보지 않은 역: 흐리게
  - 딜러가 아직 열지 않은 구역: 노선 전체가 회색 점선, "운행 전"
- 역을 누르면 바로 그 장소로 간다. 이동은 서버에 장소 하나만 쓴다(쓰기 한 번).
- 노선도는 SVG로 그린다. 휴대폰에서는 손가락으로 끌어 보고 두 손가락으로 확대한다.

| 노선 (구역) | 역 |
|---|---|
| 휠 광장 (종착역) | 광장, 역 승강장, 판돈로, 환전가, 대합촌, 하우스 로비 |
| 한빛특구선 | 중앙 전광판 광장, 길드로, 불야동, 탑 로비 |
| 로엔하임선 | 성문 광장, 칼드록, 마왕성 알현실 |
| 중원선 | 저잣거리, 운표가, 취선포, 흑전각 계단 |
| 섹터9선 | 네온 대로, 다운링크, 글리치로, 본사 로비 |
| 궤도선 | 중앙 복도, 제3갑판, 성간장터, 중앙 기관실 |
| 벨루체선 | 마차 길, 대무도회장, 로제뜰, 살롱 카드 탁자 |
| 무월리선 | 안개 마을 길, 녹슨못, 잠귀촌, 호텔 로비 |

## 3. ② 장면

```
┌─[금 테두리 · 구역 문장]──────────────┐
│  ░░ 배경 (딜러 이미지 또는 기본 그림) ░ │
│  판돈로 · 휠 광장                     │
│  붉은 네온, 젖은 돌길, 주사위 구르는 소리 │
│  (에이든) (벨라) (금만량)              │  ← 여기 있는 사람
├─────────────────────────────────────┤
│ > 판돈로 끝, 하우스의 금빛 문이 열린다.  │
│ 벨라: 어서 와요. 여긴 처음이죠?         │
│ 에이든 *주사위를 집어 든다*             │
│ 🎲 2d6 → 5·4 = 9                      │
│ [⚡][ 말하기…               ][보내기]   │
└─────────────────────────────────────┘
```

- **휴대폰:** 위에 배경 카드(화면 높이의 약 30%, 접으면 한 줄 띠), 아래가 채팅.
- **PC:** 왼쪽에 배경 카드와 사람들, 오른쪽에 채팅. 또는 배경을 위쪽에 넓게 깔고 채팅을 그 아래 가운데에 둔다(구현 때 둘을 비교해 고른다).
- **여기 있는 사람:** 초상이 한 줄로 선다. 말하는 사람의 초상이 잠깐 밝아지고 살짝 떠오른다. 접속하지 않은 사람은 흐리게.
- **NPC:** 딜러가 NPC 이름으로 말하면 그 NPC 초상이 줄에 들어온다. 딜러가 "퇴장"을 누를 때까지 남는다.
- **감각 묘사 한 줄:** 장소마다 기본 문구가 있다(자료 02-style의 구역별 감각 단어). 딜러가 장면 중에 바꿀 수 있다.

### 3-1. 배경 카드의 층

| 층 (아래→위) | 내용 |
|---|---|
| 1. 그림 | 딜러가 올린 이미지. 없으면 기본 그림(3-2) |
| 2. 통일 필터 | 구역 색으로 물들이기 + 가장자리 어둡게 + 아주 옅은 종이 질감 |
| 3. 틀 | 금 테두리, 모서리 장식, 구역 문장 |
| 4. 이름판 | 장소 이름, 구역, 감각 묘사 한 줄 |
| 5. 연출 | 딜러가 켠 효과 (3-3) |

**필터 세기** (이미지마다 고름)

| 세기 | 하는 일 | 쓸 때 |
|---|---|---|
| 은은하게 (기본) | 구역 색을 25% 정도 덮고, 채도를 조금 낮추고, 가장자리를 어둡게 | 대부분의 사진·그림 |
| 강하게 | 구역 색 두 톤(듀오톤)으로 바꿈. 어떤 이미지든 완전히 한 세트처럼 보인다 | 화풍이 제각각인 이미지를 섞을 때 |
| 틀만 | 색 보정 없이 테두리·이름판만 | 원본 색이 중요한 그림 |

필터는 CSS로 브라우저에서 입힌다. 원본은 그대로 저장되므로 언제든 세기를 바꿀 수 있다.

### 3-2. 기본 그림 (이미지가 없을 때)
구역마다 아르데코 포스터풍 카드. 구역 색 그라데이션 + 금선 무늬 + 그 구역의 실루엣 하나.

| 구역 | 색 | 실루엣 |
|---|---|---|
| 휠 광장 | 에메랄드·금 | 역 시계탑과 룰렛 휠 |
| 한빛특구 | 청록·흰 빛 | 구름을 뚫은 검은 탑, 전광판 |
| 로엔하임 | 호박·흑 | 언덕 위 검은 성, 첨탑 |
| 중원 | 주홍·먹 | 기와 지붕, 구름 위 흑전각, 등롱 |
| 섹터9 | 자홍·남 | 마천루와 기업 로고, 빗줄기 |
| 궤도 정거장 | 청록·은 | 격벽 창 너머 궤도 고리 |
| 벨루체 | 장미·금 | 샹들리에와 장미 넝쿨 |
| 무월리 | 회녹·검 | 안개 속 호텔, 꺼진 등롱 (달 없음) |

같은 구역의 역들은 같은 실루엣에 장소 이름과 무늬만 다르다. SVG로 그려서 코드에 둔다(읽기 비용 0).

### 3-3. 연출 효과
딜러 화면의 버튼으로 장면에 켜고 끈다. 모두가 같은 순간에 본다.

| 효과 | 모습 |
|---|---|
| 흔들림 | 카드가 한 번 크게 흔들린다 (폭발, 충격) |
| 경보 | 붉은 빛이 천천히 깜빡인다 |
| 정전 | 카드가 어두워지고 이름판만 희미하게 남는다 |
| 비 | 빗줄기가 내린다 |
| 안개 | 안개가 천천히 흐른다 (무월리 기본) |
| 금빛 | 금가루가 반짝이며 떨어진다 (해방, 축하) |

"움직임 줄이기" 설정을 켠 사람에게는 정지 화면으로 보인다.

## 4. 딜러 이미지

### 4-1. 올리기
- 딜러 화면 › **장면** 탭 › 장소 선택 › "이미지 올리기".
- 브라우저에서 가로 1600px 안팎, WebP 수백 KB로 줄여서 올린다. 원본 파일은 올리지 않는다.
- 이미지마다 적는 것: 이름("판돈로 · 밤"), 필터 세기, 그림 위치 맞추기(위·가운데·아래), 출처 메모(딜러만 봄).
- 한 장소에 여러 장을 올릴 수 있다.

### 4-2. 바꿔 끼우기
- 장소마다 "지금 보이는 그림"이 하나 있다. 딜러가 목록에서 누르면 그 장소에 있는 모두의 화면이 천천히 바뀐다(페이드).
- 감각 묘사 한 줄도 그림마다 따로 적어 둘 수 있다. 그림을 바꾸면 문구도 같이 바뀐다.

### 4-3. NPC 초상
- 딜러 화면 › **NPC** 탭에서 NPC를 만든다: 이름, 소속 구역, 초상 이미지, 말투 메모(딜러만 봄).
- 초상도 같은 필터와 둥근 금테 틀을 쓴다. 이미지가 없으면 이름 첫 글자 문장(紋章)이 대신 선다.
- 세계관 NPC(지배인, 일곱 보스, 성녀, 역무원, 금만량, 곽두 등)는 이름과 구역만 미리 만들어 둔다. 초상은 딜러가 채운다.

### 4-4. 채팅 장면 컷 (4단계)
- 딜러가 채팅에 그림 한 장을 띄운다. 같은 틀을 씌워 채팅 폭으로 크게 보인다. 보스 등장 같은 순간에 쓴다.
- 장면 컷은 장소 이미지 목록과 별도로 쌓이고, 다시 꺼내 쓸 수 있다.

## 5. 채팅

1판 1단계에서 만든 채팅을 그대로 쓰고 넓힌다.

| 채널 | 누가 보나 | 쓰임 |
|---|---|---|
| 장소 | 그 장소에 들른 사람 (딜러는 전부) | 기본 RP |
| 전체 | 모두 | 장소와 상관없는 이야기, 세션 시작·끝 |
| 귓속말 | 보낸 사람, 받는 사람, 딜러 | 비밀 이야기 |
| 공지 | 모두 (딜러만 씀) | 장면 묘사, 탑 시스템 창, 호텔 안내문 |

- 마크다운(굵게, 기울임, 취소선, 가리기, 코드, 인용), `/행동`·`*행동*`, `/주사위 2d6+1`(봉인), 고치기·지우기. 주사위는 고치거나 지울 수 없다.
- 딜러는 "딜러", 아무 NPC, 이름 없는 묘사(공지 모양)로 쓸 수 있다.
- 명령: `/특기 쾌검 5`(특기 결제, 4단계), `/귓 이름 텍스트`, 딜러 전용 `/공지`, `/npc 이름`.
- 기존 화면 바로 가기: `[[일터]]`, `[[하우스]]`, `[[거래소:FTN]]`.
- 지도 말풍선은 없어지고, 대신 장면의 초상 줄에서 말하는 사람이 밝아진다.

## 6. 캐릭터 초상

- 1판의 도트 캐릭터 꾸미기를 초상 만들기로 쓴다. 장면의 초상 줄과 채팅 얼굴에 같은 그림이 쓰인다.
- **결정 (2026-10-15):** 플레이어도 자기 초상 이미지를 올릴 수 있다(정사각형 512px, 같은 필터와 틀). 안 올리면 도트 초상.

## 7. 세션과 기록

- 세션: 딜러가 열고 닫는다(제목 입력). 깜빡하면 새벽 4시(KST)에 자동으로 닫힌다. 세션 밖에서도 RP는 된다.
- 채팅은 남긴다. 위로 넘기면 지난 글이 계속 나온다(50개씩).
- 명장면 📌 고정, 세션 로그 내려받기(마크다운 파일), 도시 연대기(장부에 남는 특기 결제·주사위·맞붙기·해방을 세션별로 정리).

## 8. 데이터

| 경로 | 쓰는 쪽 | 내용 |
|---|---|---|
| `actors/{pid}` | 플레이어 | 이름, 초상(꾸미기 값), 지금 장소, 마지막 접속(`seenAt`). 1판의 걷기 칸(fx…ty)은 뺀다 |
| `reads/{pid}` | 플레이어 | 장소별로 마지막에 본 시각 (노선도의 새 글 점) |
| `discoveries/{pid}` | 플레이어 | 가 본 장소 |
| `scenes/{placeId}` | 딜러 | 지금 보이는 이미지 id, 감각 묘사 문구, 켜진 효과, 무대에 선 NPC |
| `sceneImages/{id}` | 딜러 | 장소 id 또는 NPC id, Storage 경로, 이름, 필터 세기, 위치, 문구, 출처 메모 |
| `npcs/{id}` | 딜러 | 이름, 구역, 초상 이미지 id, 말투 메모(딜러만 읽음: `npcs/{id}/secret/notes`) |
| `lines/{district}` | 딜러 | 노선 운행 여부 (운행 전 / 운행) |
| `messages/{id}` | 플레이어, 딜러 | 1판과 같음 + 글쓴이 종류(PC·NPC·딜러·묘사), 이미지 메시지(4단계) |
| `sessions/{id}` | 딜러 | 제목, 연 시각, 닫은 시각 |
| Storage `scene/{id}.webp` | 딜러 | 이미지 파일 |

- 역 목록·노선·기본 그림·기본 문구는 코드(`packages/core/src/city`)에 둔다.
- 보안 규칙: 이미지·장면·NPC·노선은 딜러만 쓴다. 플레이어는 자기 `actors`·`reads`·`discoveries`만 쓴다. 메시지 규칙은 1판과 같고, 딜러는 NPC·묘사로 쓸 수 있다. Storage는 딜러만 올리고 로그인한 사람은 읽는다.

## 9. 비용 (Blaze)

| 항목 | 세션 하나 (5명, 3시간, 메시지 800개) |
|---|---|
| 쓰기 | 메시지 800 + 장소 이동·접속 정보 수백 ≈ 1,500 |
| 읽기 | 각 메시지를 같은 장소·채널 사람 수만큼 ≈ 5,000 |
| 이미지 | 장면에 들어갈 때 한 번 내려받음(브라우저 캐시). 수백 KB × 사람 수 |
| 저장 | 이미지 30~100장 × 수백 KB = 수십 MB → 한 달 몇십 원 |

1판의 걷기 쓰기(이동마다 한 번)가 없어져 오히려 줄어든다.

## 10. 구현 단계

| 단계 | 내용 |
|---|---|
| **1** | 노선도(일곱 노선, 30역, 사람·새 글·가 본 곳 표시), 장면 화면(기본 카드 그림 8종, 초상 줄, 채팅 이동), 장소 이동, 걷는 지도 걷어 내기 |
| **2** | 딜러 도구: 장면 탭(이미지 올리기·필터·바꿔 끼우기·문구), NPC 탭(초상·NPC로 말하기·등장·퇴장), 공지, 노선 운행, 연출 효과 버튼, 세션 |
| **3** | 귓속말, 채팅 안의 특기 결제, 웃돈 경쟁 장면, 명장면, 세션 로그, 도시 연대기 |
| **4** | 채팅 장면 컷, (6절 결정에 따라) 플레이어 초상 이미지 |

1단계만 끝나도 노선도와 장면에서 바로 RP를 할 수 있다(그림은 기본 카드).
2단계부터 딜러가 그림을 채워 넣으며 도시가 자란다.

## 11. 1판에서 바뀐 것 (결정 기록)

- **2026-10-15 (1판):** 도트 JRPG 걷는 지도로 설계하고 1단계(휠 광장 여섯 곳, 캐릭터 꾸미기, 걷기, 채팅, 주사위)를 만들어 배포했다.
- **같은 날 (2판):** 써 보니 걷는 지도는 RP에 맞지 않았다.
  - 글과 그림으로 표현하는 쪽이 상상력을 더 자극한다.
  - 도트 그림으로 NPC와 앞으로의 모든 사건 연출을 표현하려면 이야기가 진행될 때마다 만드는 일이 계속 늘어난다.
  - 그래서 이야기 전개에 드는 품이 가장 적은 방식으로 바꿨다: 노선도 + 장면 + 딜러가 올리는 이미지.
- 1판에서 그대로 쓰는 것: 채팅(마크다운, 주사위, 고치기·지우기), 캐릭터 꾸미기, 장소 데이터, 보안 규칙의 큰 틀.
- 걷어 내는 것: 걷기·길찾기·키보드 이동, 도트 타일 지도. 휠 광장 도트 그림은 통일을 위해 쓰지 않는다.

## 12. 구현 메모 (설계와 다르게 만든 곳)

- **공지 채널 대신 서술:** 따로 공지 채널을 두지 않고, 딜러가 "서술"로 말하면 어느 채널에서나 가운데 정렬 금테 줄로 보인다. `/판정 …`은 판정 카드.
- **NPC로 말하기:** `/npc` 명령 대신 입력창 위 "말하는 이" 고르기(서술 · 딜러 · NPC 목록). 장면 콘솔의 💬로도 고른다.
- **가 본 역:** `discoveries` 대신 `reads/{pid}`에 기록이 있으면 가 본 역으로 친다.
- **새 글 점:** 장소마다 `placeActivity/{place}`(마지막 글 시각·이름)를 두고 `reads`와 비교한다.
- **노선 운행:** `lines/{district}` 대신 `config/city.closedLines`. 운휴 노선의 역으로는 새로 갈 수 없고, 있던 사람은 머문다.
- **귓속말:** 채널 `whisper:<A>~<B>`(정렬). 딜러와는 `gm`. 받은 편지함은 내 채널 목록을 `in` 질의(30개씩)로 듣는다. 딜러는 모든 귓속말을 읽고, 플레이어끼리의 것은 읽기만 한다. 안 읽은 표시는 브라우저에만 저장.
- **특기 결제 카드:** 특기 장부(`paySkill`)로 먼저 결제하고, 메시지 id를 `skill_<장부 id>`로 묶어 한 결제는 한 번만 보인다. 규칙이 장부의 특기 이름·점수·금액과 같은지 확인한다.
- **맞붙기(웃돈 경쟁 장면):** 딜러가 장소에 맞붙기를 열면 그동안 그 장소에서 쓴 특기 결제가 점수판에 오른다(높은 점수 순). 상대 점수는 딜러가 걸고, "결과 발표하고 닫기"가 판정 카드를 올린다.
- **세션 기록:** 세션이 열려 있는 동안의 공개 메시지에 `sessionId`가 붙고, 기록 탭에서 마크다운 파일로 내려받는다(귓속말 제외). 도시 연대기(장부 정리)는 명장면 + 세션 기록으로 대신했다.
- **이미지 저장:** Storage `uploads/{올린 사람 uid}/{이미지 id}.webp`. 각자 자기 폴더에만 3MB 미만 이미지를 올리고, 어디에 쓰일지는 Firestore `sceneImages` 규칙이 정한다(플레이어는 자기 초상만).
- **바로 가기:** 채팅의 `[[일터]]`, `[[거래소:FTN]]`처럼 쓰면 그 화면으로 가는 단추가 된다.
