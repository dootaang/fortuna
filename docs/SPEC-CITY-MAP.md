# 도시 지도와 RP 채팅 설계

> 상태: 설계 확정 (2026-10-15). 아직 구현하지 않았다. 시작 신호가 오면 10절 1단계부터 만든다.
> 디스코드에서 하던 RP 전체를 이 웹앱으로 옮긴다. 디스코드와는 연동하지 않는다.

캐릭터는 도트 그림 JRPG식 도시 지도를 걸어 다니며, 옆의 채팅창으로 RP를 한다. 코코포리아나 Roll20 같은 사이트와 비슷하지만,
포르투나 경제(특기 결제, 봉인된 주사위, 장부)가 채팅 안에 들어와 있다는 점이 다르다.

## 0. 확정된 결정

| # | 질문 | 결정 |
|---|---|---|
| 1 | RP를 어디서 하나 | 전부 웹앱. 디스코드 연동 없음 |
| 2 | 알림 | 없음. 들어와서 보는 방식 |
| 3 | 채팅 기록 | 남긴다(비용이 작다, 9절). 세션 단위로 묶고, 명장면 고정과 세션 로그 내려받기를 둔다 |
| 4 | 세션 | 딜러가 열고 닫는다. 깜빡하면 새벽 4시(KST)에 자동으로 닫힌다 |
| 5 | 지도는 누가 만드나 | Claude가 타일 그림과 지도 데이터를 코드로 만든다 |
| 6 | 그림체 | 16비트 도트 지도 + 지금 앱의 아르데코 화면 틀 |
| 7 | 캐릭터 모습 | 도트 캐릭터 꾸미기 (머리·옷·색) |
| 8 | 움직임 | 목적지를 누르면 길을 찾아 걸어간다. 캐릭터끼리는 겹쳐 지나간다 |
| 9 | 말은 누가 움직이나 | 플레이어는 자기 말만. 딜러는 NPC 말과 모든 말 |
| 10 | 전장의 안개 | 시야형 안개는 없음. 장소 전환 + GM 숨김층 + 발견 기록 + 무월리 연출 안개 |
| 11 | 채팅 구조 | 장소별 채팅 + 전체 채널 + 귓속말 + GM 공지·NPC 발언, 마크다운 |
| 12 | 기존 기능 | 채팅 안에서 특기 결제, 봉인된 주사위, 기존 화면 바로 가기 |
| 13 | 지도와 메뉴 | 지도는 RP 전용으로 따로 둔다. 기존 메뉴(로비·일터·도박장·특기·지갑)는 그대로 |

## 1. 화면

- 하단 메뉴에 **도시** 칸을 하나 더한다: 로비 · **도시** · 일터 · 도박장 · 특기 · 지갑 (6칸).
- **휴대폰:** 위쪽 55%에 지도, 아래쪽에 채팅. 채팅을 끌어올리면 지도가 작아진다. 채팅 위에 [장소 · 전체 · 귓속말] 탭.
- **PC:** 왼쪽에 지도, 오른쪽에 채팅 (코코포리아 배치).
- 지도 위 정보:
  - 맨 위에 장소 이름과 구역 표시 ("휠 광장 › 판돈로")
  - 오른쪽 위에 지금 이 장소에 있는 사람 목록
  - 아래에 "지도 목록" 버튼: 가 본 장소와 안 가 본 장소. 안 가 본 곳은 흐리게
- 아르데코 틀 안에 도트 지도가 들어가는 구성이다. 틀은 지금 앱의 금색 테두리와 장식을 그대로 쓴다.

## 2. 지도

### 2-1. 만드는 방식
- **타일 지도.** 한 칸은 16×16 도트. 화면에는 정수 배율(휴대폰 3배, PC 3~4배)로 확대해 도트가 뭉개지지 않게 그린다.
- **타일 그림은 글자 격자로 쓴다.** 도트 한 칸을 팔레트 글자 하나로 적고, 앱이 처음 열릴 때 캔버스에 한 번 그려 둔다.
  그림 파일이 아니라 코드라서 고치기 쉽고, 구역마다 팔레트만 바꿔 색을 낼 수 있다.

  ```
  // 예: 휠 광장 바닥 돌 타일 (a = 진한 돌, b = 밝은 돌, c = 이음새)
  "aaaaaaacaaaaaaac",
  "abbbbbacabbbbbac",
  ...
  ```
- **지도도 데이터다.** `packages/core/src/content/maps/`에 장소마다 파일 하나. 바닥층, 물건층, 위층(지붕·간판처럼 캐릭터 위로 덮이는 것), 출입구, 시작 위치가 들어 있다.
- **걸을 수 있는지는 타일이 안다.** 벽·물·가구 타일은 못 지나간다. 길찾기용 데이터를 따로 만들 필요가 없다.
- 지도는 Firestore가 아니라 코드에 있다. 읽기 비용이 0이고, 바꾸면 배포로 반영된다. 나중에 딜러 지도 편집기(10절 5단계)를 만들면 그때 Firestore에 덮어쓰기 층을 둔다.
- 크기는 장소마다 20×15~48×36칸. 큰 광장은 화면이 캐릭터를 따라간다.

### 2-2. 장소 목록
세계관 문서(`자료/fortuna-gm` 01·04)의 장소를 그대로 쓴다. 구역마다 바깥 지도 하나 + 안쪽 장소 2~4개.

| 구역 | 바깥 지도 | 안쪽 장소 |
|---|---|---|
| 휠 광장 | 광장 (역 앞) | 역 승강장, 판돈로, 환전가, 대합촌, 하우스 로비 |
| 한빛특구 | 중앙 전광판 광장 | 길드로, 불야동, 탑 로비 |
| 로엔하임 | 성문 광장 | 칼드록, 마왕성 알현실 |
| 중원 | 저잣거리 | 운표가, 취선포 (객잔), 흑전각 계단 |
| 섹터9 | 네온 대로 | 다운링크, 글리치로, 본사 로비 |
| 궤도 정거장 | 중앙 복도 | 제3갑판, 성간장터, 중앙 기관실 |
| 벨루체 | 마차 길 | 대무도회장, 로제뜰, 살롱 카드 탁자 |
| 무월리 | 안개 마을 길 | 녹슨못, 잠귀촌, 호텔 로비 |

모두 합쳐 30개 안팎이다. 휠 광장부터 만든다(10절).

- 구역끼리는 **휠 광장에서 갈라지는 길**로 잇는다. 휠 광장 바깥 지도 가장자리에 구역마다 출구가 있다.
- 장소마다 **구역별 감각 단어**(02-style)를 그림으로 옮긴다. 예: 중원은 등롱·기와·표국 수레, 섹터9는 네온 간판·빗물 웅덩이, 무월리는 꺼진 등롱·안개.
- 장식 애니메이션 몇 가지: 깜빡이는 네온, 흔들리는 등롱, 돌아가는 휠 광장 분수, 궤도 정거장 표시등.

### 2-3. 안개 대신
| 장치 | 하는 일 |
|---|---|
| 장소 전환 | 출입구 칸을 밟으면 다음 장소로 넘어간다. 안쪽 장소는 들어가야 보인다 |
| GM 숨김층 | 딜러만 보는 말과 물건. 딜러가 "공개"를 누르면 모두에게 보인다 (예: 객잔 구석의 금만량, 서랍 속 쪽지) |
| 발견 기록 | 플레이어마다 가 본 장소를 기록한다. 지도 목록에서 안 가 본 곳은 흐리게 보인다 |
| 무월리 연출 안개 | 무월리 지도에서만 캐릭터 주변 몇 칸만 밝고 나머지는 어둡다. 승패와 상관없는 분위기 연출 |

## 3. 캐릭터

### 3-1. 도트 캐릭터 꾸미기
- 처음 도시에 들어올 때 한 번 만들고, 언제든 바꿀 수 있다.
- 고르는 것: 피부색, 머리 모양(8가지), 머리 색, 옷(8가지: 정장, 로브, 도포, 갑옷, 코트, 드레스, 작업복, 우주복), 옷 색, 소품(없음·모자·안경·뿔·고양이 귀·의체 눈).
  세계관 장르(무협·판타지·사이버펑크 등)가 다 들어가게 골랐다.
- 그림은 층을 겹쳐 만든다: 몸 + 옷 + 머리 + 소품. 방향 4개 × 걷기 3프레임.
- 저장은 고른 값 몇 개뿐이다(`players/{pid}.sprite`). 그림은 브라우저가 매번 조립한다.
- 이름표는 캐릭터 머리 위에 작게. 접속하지 않은 캐릭터는 반투명하게 그 자리에 남는다("자리 비움").

### 3-2. NPC
- 딜러가 NPC를 만들고 지도에 세운다. 이름, 도트 모습(같은 꾸미기 도구), 소속 구역.
- 세계관 NPC 카드(지배인, 일곱 보스, 성녀, 역무원, 금만량 등)는 미리 만들어 둔다. 지배인은 처음엔 지도에 나오지 않는다(세계관: 초반엔 편지로만 존재).

### 3-3. 움직임
- 지도를 누르면 그 칸까지 최단 경로(A*)를 찾아 걷는다. 길이 없으면 갈 수 있는 가장 가까운 칸까지 간다.
- 저장은 출발할 때 한 번: `{ 출발 칸, 도착 칸, 출발 시각 }`. 경로는 모두의 화면이 같은 지도로 똑같이 계산해 재생한다. **이동 한 번 = 쓰기 한 번.**
- 걷는 속도는 초당 5칸. 중간에 다른 곳을 누르면 지금 위치에서 새로 출발한다.
- 캐릭터끼리는 겹쳐 지나간다. 좁은 골목에서 서로 막히지 않게 하기 위해서다.
- 출입구 칸에 닿으면 다음 장소로 넘어가고, 그 장소의 정해진 칸에 나타난다.
- 이동은 경제와 상관없으므로 보안 규칙은 "자기 말인지"와 "지도 안 칸인지"만 본다.

## 4. 채팅

### 4-1. 채널
| 채널 | 누가 보나 | 쓰임 |
|---|---|---|
| 장소 | 지금 그 장소에 있는 사람 (딜러는 전부) | 기본 RP. 같은 객잔에 있는 사람끼리 |
| 전체 | 모두 | 장소와 상관없는 이야기, 세션 시작·끝 |
| 귓속말 | 보낸 사람과 받는 사람 (딜러는 볼 수 있음) | 비밀 이야기 |
| 공지 | 모두 (딜러만 씀) | 장면 묘사, 탑 시스템 창, 호텔 안내문 |

- 장소 채널은 그 장소에 들어온 뒤의 글만 보이는 게 아니라, 그 장소에서 오간 글이 다 보인다. 늦게 온 사람이 앞 이야기를 읽을 수 있게 하기 위해서다.
- 딜러는 장소 채널을 고르는 목록이 따로 있어서, 어디서 무슨 이야기가 오가는지 다 본다.

### 4-2. 메시지
- **누구 이름으로:** 플레이어는 자기 캐릭터. 딜러는 "딜러", 아무 NPC, 또는 이름 없는 묘사로 쓸 수 있다.
- **얼굴:** 메시지 옆에 캐릭터 도트 얼굴(꾸미기에서 잘라 낸 것).
- **마크다운:** 굵게, 기울임, 취소선, 인용(`>`, 탑 시스템 창·호텔 안내문), 스포일러, 줄바꿈, 코드. 그림과 HTML은 막는다.
- **긴 글:** 디스코드식 소설체 RP를 쓰기 편하게, 입력창은 여러 줄로 늘어나고 2,000자까지.
- **고치기와 지우기:** 자기 글은 고칠 수 있고 "고침" 표시가 붙는다. 지우면 "지운 글"만 남는다.
- **말풍선:** 장소 채널에 쓴 글의 첫 줄은 지도 위 캐릭터 머리 위에 몇 초 동안 말풍선으로 뜬다. 지도를 보면서 누가 말하는지 알 수 있다.

### 4-3. 명령
| 명령 | 하는 일 |
|---|---|
| `/행동 텍스트` 또는 `*텍스트*`로 시작 | 행동 묘사 (다른 색, "에이든이 잔을 내려놓는다") |
| `/주사위 2d6+1` | 봉인된 주사위 (4-4) |
| `/특기 쾌검 5` | 특기 결제 확인 창 → 결제하면 채팅에 "쾌검 5점, 1,300코인이 탄다" 연출 (기존 특기 결제와 같은 장부) |
| `/귓 이름 텍스트` | 귓속말 |
| `/공지`, `/npc 이름` | 딜러 전용 |

- 채팅창 옆 **⚡ 버튼**에서 같은 일을 눌러서도 할 수 있다(휴대폰에서 명령어 치기가 번거로우므로).
- 기존 화면 바로 가기: 메시지 안의 `[[일터]]`, `[[하우스]]`, `[[거래소:FTN]]`은 누르면 그 화면으로 간다.

### 4-4. 봉인된 주사위
- 주사위 메시지를 쓸 때 식(`2d6+1`)만 적고, 서버 시각이 함께 찍힌다.
- 결과는 `메시지 id + 서버 시각`에서 정해진다. 도박 게임에 쓰는 봉인 방식과 같다. 누구도 결과를 미리 알거나 고를 수 없고, 모두의 화면이 같은 결과를 계산한다.
- 굴림 연출은 지금 도박장의 3D 주사위를 작게 쓴다.

### 4-5. 웃돈 경쟁 (보스전)
세계관의 "맞붙기"와 "웃돈"을 채팅 안에서 진행하는 장면 도구다(10절 4단계).
- 딜러가 "맞붙기 열기"로 양쪽(보스 대 플레이어들)을 정한다.
- 플레이어는 특기를 쓰고, 한 단계씩 웃돈을 얹는다. 결제는 기존 특기 결제 장부로 한다.
- 채팅에 점수와 탄 코인이 쌓여 보이고, 딜러가 결과를 선언한다.

## 5. 세션과 기록

- **세션:** 딜러가 "세션 열기"(제목 입력)와 "세션 닫기"를 누른다. 닫는 걸 잊으면 새벽 4시(KST)에 자동으로 닫힌다.
- 세션이 닫혀 있어도 플레이어는 지도를 걸어 다니고 채팅할 수 있다. 그 글은 "세션 밖"으로 묶인다(평소 일상 RP).
- **채팅은 남긴다.** 채널마다 위로 넘기면 지난 글이 계속 나온다(한 번에 50개씩).
- **명장면:** 누구나 메시지에 📌을 달 수 있다. 정보 칸의 "명장면 모음"에 세션별로 모인다.
- **세션 로그 내려받기:** 세션 하나의 전체 채팅을 텍스트(마크다운) 파일 하나로 받는다. 딜러와 플레이어 모두.
- **도시 연대기:** 특기 결제, 주사위, 맞붙기 결과, 구역 해방처럼 장부와 이벤트에 남는 일은 채팅과 별도로 세션별 연대기로 자동 정리된다.

## 6. 데이터

| 경로 | 쓰는 쪽 | 내용 |
|---|---|---|
| `players/{pid}.sprite` | 플레이어 | 캐릭터 꾸미기 값 |
| `actors/{id}` | 플레이어(자기 것), 딜러 | 지도 위 말: 종류(PC·NPC), 장소, 출발·도착 칸, 출발 시각, 방향, 숨김 여부 |
| `presence/{pid}` | 플레이어 | 마지막 접속 시각 (앱이 열려 있으면 1분마다) |
| `discoveries/{pid}` | 플레이어 | 가 본 장소 목록 |
| `messages/{id}` | 플레이어, 딜러 | 채널, 글쓴이(종류·id·표시 이름), 본문, 종류(말·행동·주사위·특기·공지), 세션 id, 시각, 고침·지움, 핀 |
| `sessions/{id}` | 딜러 | 제목, 연 시각, 닫은 시각 |
| `npcs/{id}` | 딜러 | NPC 이름, 모습, 구역 |

인덱스: `messages`의 (채널, 시각), (세션, 시각), (핀, 시각).

### 보안 규칙
- `actors`: 플레이어는 자기 PC 말만 고친다. 장소는 지도 목록에 있는 것, 칸은 지도 범위 안. 숨긴 말은 딜러만 읽는다.
- `messages`: 글쓴이가 자기여야 한다(딜러는 NPC·묘사로 쓸 수 있음). 시각은 서버 시각. 귓속말은 보낸 사람·받는 사람·딜러만 읽는다. 고치기는 자기 글만, 본문과 "고침" 표시만.
- 특기 결제 메시지는 같은 묶음에서 만들어진 특기 장부를 가리켜야 한다(지금 이벤트 문서와 같은 방식). 채팅으로 코인이 오가는 경로를 새로 만들지 않는다.

## 7. 그리기와 성능

- **Canvas 2D**로 그린다. 장소 하나의 바닥·물건층은 처음에 한 장의 그림으로 미리 그려 두고, 매 프레임에는 캐릭터·말풍선·위층·애니메이션 소품만 그린다.
- 휴대폰에서 60프레임을 목표로 하고, 연출 설정의 "움직임 줄이기"를 따르면 장식 애니메이션을 멈춘다.
- 지도를 손가락으로 끌어 둘러볼 수 있고, 두 손가락으로 확대·축소(2~4배)할 수 있다. 내 캐릭터 버튼을 누르면 다시 따라간다.
- 구독하는 것: 지금 장소의 말들, 지금 채널의 최근 메시지 50개, 접속 정보. 장소를 바꾸면 구독도 바뀐다.

## 8. 세계관 지키기

- 기차가 왜 오고 왜 사라지는지는 지도에서도 설명하지 않는다. 역 승강장에는 선로만 있고 기차는 없다(도착 장면 때 딜러가 연출).
- 지배인은 초반에 지도에 나오지 않는다. 하우스 로비의 빈 액자(GM 전용 단서)는 GM 숨김층에 둔다.
- NPC 말투는 `자료/fortuna-gm/03-npc.md`를 따른다. 지도 문구(간판, 안내문)는 02-style을 따른다.
- 플레이어 캐릭터의 행동을 시스템이 대신 쓰지 않는다. 자동 문구는 "코인이 탄다", "주사위가 멈춘다" 같은 사물 묘사만.

## 9. 비용 (Blaze)

| 항목 | 세션 하나 (5명, 3시간, 메시지 800개, 이동 300번) |
|---|---|
| 쓰기 | 메시지 800 + 이동 300 + 접속 정보 900 ≈ 2,000 |
| 읽기 | 각 쓰기를 같은 장소·채널 사람 수만큼 ≈ 6,000~8,000 |
| 저장 | 메시지 1개 약 1KB → 세션당 약 1MB |
| 돈 | 세션 하나에 약 2센트 미만. 13주 동안 매일 해도 몇 달러 |

지도와 타일 그림은 코드에 있어 읽기 비용이 없다. Firebase Storage는 쓰지 않는다(그림을 올리지 않으므로).

## 10. 구현 단계

| 단계 | 내용 |
|---|---|
| **1** | 휠 광장(바깥 + 역 승강장·판돈로·환전가·대합촌·하우스 로비), 타일 그리기 엔진, 캐릭터 꾸미기, 걷기와 장소 전환, 장소·전체 채팅(마크다운, 말풍선), 봉인된 주사위, 접속 정보 |
| **2** | 나머지 일곱 구역의 바깥 지도와 안쪽 장소, 발견 기록, 지도 목록 |
| **3** | 딜러 도구: 세션 열기·닫기, NPC 만들기와 배치, NPC로 말하기, 공지, GM 숨김층, 귓속말 |
| **4** | 채팅 안의 특기 결제, 웃돈 경쟁 장면, 명장면 고정, 세션 로그 내려받기, 도시 연대기 |
| **5** | 무월리 연출 안개, 장식 애니메이션 확대, 딜러 지도 편집기 |

1단계가 끝나면 휠 광장에서 바로 RP를 시작할 수 있다. 지도는 단계마다 장소를 늘려 간다.
각 단계는 화면 테스트(e2e)와 보안 규칙 테스트를 같이 넣는다.

## 11. 남은 질문 (구현 중 정해도 되는 것)

- 지도 그림체는 휠 광장 첫 시안을 보여 드리고 확정한 뒤 나머지 구역에 쓴다.
