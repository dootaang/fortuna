# 딜러 안내서

주소: **https://fortuna-472e3.web.app** (플레이어) · **https://fortuna-472e3.web.app/dealer** (딜러)

## 처음 한 번

1. `/dealer`에서 **Google로 로그인**합니다.
2. "딜러 등록이 필요합니다" 화면에 나온 **UID를 복사**합니다.
3. [Firebase 콘솔](https://console.firebase.google.com/project/fortuna-472e3/firestore/databases/-default-/data) › Firestore › 데이터 탭 ›
   **컬렉션 시작** › 컬렉션 ID `admins` › 문서 ID에 UID 붙여 넣기 › 필드 없이 저장.
   저장하면 화면이 자동으로 딜러 화면으로 바뀝니다.
4. **설정 › 도시 초기화**를 누릅니다. 경제 설정, 구역 8곳, 지배인 금고(1,000,000), 공동 지갑이 만들어집니다.
5. **플레이어 › + 플레이어 등록**: 이름, 소속 구역, 특기(이름·점수)를 넣으면 접속 코드가 나옵니다.
   코드를 플레이어에게 **개인 메시지로** 보내 주세요. 나중에 "코드 보기"로 다시 볼 수 있습니다.
6. 플레이어가 코드를 넣으면 지배인의 편지 → 환영 봉투 → 개찰구 연출 후 900코인, 빚 1,500으로 시작합니다.

> 딜러 계정으로 로그인한 브라우저는 플레이어가 될 수 없습니다. 플레이어 화면을 직접 보려면 시크릿 창을 쓰세요.

## 평소

- 매일 0시(한국 시간)에 일 10회, 도박 30판이 자동으로 다시 채워집니다. 주 단위로 바꾸려면 설정 › 경제 설정 › 횟수 초기화 주기.
- **현황** 탭에서 전원의 잔액, 빚, 이번 주 사용 횟수, 보유 물품을 봅니다.
- 원정 보상이나 벌금은 **플레이어 › 지급·차감**. 사유 메모가 반드시 필요하고 장부에 남습니다.
- 원정에서 쓴 소모품은 플레이어 카드의 **사용 처리**로 표시합니다.

## 대결 (PvP 도둑잡기)

- 플레이어는 도박장 화면 아래 "대결 · 도둑잡기"에서 판을 열고(판돈, 2~4명) 서로 들어갑니다. 먼저 패를 다 턴 사람이 판 전체를 가져갑니다. 하우스에서 열면 지배인 몫 5%가 떼입니다.
- 하루 도박 횟수는 쓰지 않습니다.
- **처음 한 번**: 업데이트 후 설정 › **도시 초기화**를 한 번 더 누르세요. 대결용 배분표(768개)가 만들어집니다. 이미 있으면 건너뜁니다.
- 진행 중인 판은 현황 탭 "진행 중인 대결"에서 보이고, 문제가 생기면 **무효** 처리할 수 있습니다(전원 판돈 환불).
- 판돈 범위, 지배인 몫, 시간 제한(내밀기 12초, 고르기 20초, 넘기기 8초)은 `config/economy`의 `pvp` 항목입니다.

## 환전가 거래소 (코인 시세 레버리지)

플레이어는 도박장 › **거래소**에서 아홉 종목(FTN과 구역 코인)에 롱·숏을 겁니다. 설계는 [SPEC-COIN-MARKET.md](./SPEC-COIN-MARKET.md).

- **처음 한 번**: 시세는 Cloudflare Worker(디스코드 알림과 같은 Worker)의 Durable Object 알람이 15초마다 한 틱씩 찍습니다. 1분 크론은 알람이 멈췄으면 다시 겁니다.
  1. `node scripts/create-oracle.mjs` — 기록원 전용 계정을 만들고 Worker 비밀값(ORACLE_REFRESH_TOKEN, MARKET_SECRET)을 등록한 뒤 **UID를 출력**합니다.
  2. `corepack pnpm --filter @fortuna/notifier exec wrangler deploy`
  3. 딜러 화면 › **거래소** › 기록원 UID 등록에 1번의 UID를 붙여 넣습니다. 1~2분 안에 "정상"이 뜹니다.
- **거래소 탭**: 기록원 상태, 열린 포지션과 금고 최대 노출, 문제가 생긴 포지션 **무효**(증거금 환불), 소식 발행, 설정.
- **소식 발행**: 종목·방향·세기·지속 시간·문구를 고르면 발표 시각에 시세가 움직이고 시세판과 디스코드에 문구가 뜹니다.
  귓속말을 적으면 발표 몇 분 전에 소문이 먼저 돕니다. **간부전 예고** 버튼은 그 구역 종목을 6시간 출렁이게 합니다(점프 없음).
- **자동 반영**: 구역 해방(그 구역 종목 급등, FTN 하락), 하우스 개방(WHL 상승, 배율 한도 상승), 도시의 도박 판 수(WHL),
  플레이어 빚 총액(FTN, GM 단서 — 설정에서 끌 수 있음)은 기록원이 10분마다 읽어 반영합니다.
- 서킷 브레이커: 설정에서 종목 거래를 끄면 그 종목 가격도 멈춥니다(멈춘 동안 강제 청산 없음). 전체를 끄면 기록원도 쉽니다.
- **현물**: 종목 화면 주문 칸에서 [현물 | 선물]을 고릅니다. 현물은 그냥 사고파는 것이라 이자·강제 청산이 없고, 수량은 1/10000개 단위입니다.
  매수는 하루 20회(매도는 무제한), 한 번에 10~2,000코인어치. 거래소 탭 "현물 보유"에서 누가 무엇을 들고 있는지 봅니다.
- **간부전 예고 = 진입 정지**: 간부전 일정이 잡히면 바로 거래소 탭의 구역 버튼을 누르십시오. 예고 소식이 뜨고, 해방이 시세에 반영될 때까지
  그 종목의 새 진입·매수가 멈춥니다(가진 것은 팔 수 있음). 플레이어가 급등을 미리 알고 사 두는 것을 막습니다. 간부전이 무산되면 "간부전 대기" 목록에서 해제.
- 하루 도박 횟수는 쓰지 않습니다. 선물 신규 포지션은 하루 10건, 동시 3개.
- **거래소 2부 1단계** ([SPEC-MARKET-DEPTH.md](./SPEC-MARKET-DEPTH.md)):
  - 시세판 위의 **공포·탐욕 계기판**, 종목마다 얇은 **롱/숏 막대**. 종목 화면에는 보조지표 칩(이동평균·볼린저·거래량·RSI), 롱/숏 금액, **청산 지도**.
  - 이 숫자들에는 **주민 군중(NPC 거래자)**의 가상 포지션이 섞여 있어서 플레이어끼리 서로의 금액을 알아낼 수 없습니다. 군중은 코인을 움직이지 않고 시세도 움직이지 않습니다.
    설정 › "NPC 거래자"로 끄거나 규모를 바꿉니다.
  - **환전가 특별 징수**: 한 주(월요일 0시부터) 거래소 순이익(선물 + 현물, 손실 상계)이 5,000코인을 넘는 몫은 지급하지 않고 금고에 남깁니다.
    거래소 탭 "이번 주 거래소 순이익"에서 누가 얼마나 벌었는지 봅니다. 설정 › "주간 수익 상한"에서 금액을 바꾸거나 0으로 끕니다.
- **거래소 2부 2단계 (실적·리포트·금리)**:
  - 매일 21시 구역마다 **실적 발표**(월 HBT·ORB, 화 S9, 수 LNH, 목 JWN, 금 BLC·MWL, 토 WHL, 일 FTN 도시 경기 보고). 실적 = NPC 주민 몫(비밀) + 플레이어 주민 몫(일·상환·특기, 최대 ±6%).
    발표가 기준가를 조금씩 옮겨서, 구역 주민이 열심히 일하면 그 구역 코인이 오릅니다.
  - 다음 날 정오에 구역 NPC의 **애널리스트 리포트**(적정가 밴드). 필자마다 버릇이 있고, 적중 기록이 쌓여 보입니다.
  - 플레이어는 거래소 › **시장 정보**에서 일정, 구역 실적판(예상치·업계 분위기·주민 활동), 리포트를 봅니다.
  - **지배인 금리 결정**: 거래소 탭에서 새 이자율과 시각을 예고하면 일정에 바로 뜨고, 그 시각에 시세가 움직이며 이자율이 바뀝니다(0.05%p 인상마다 FTN −2%).
  - 설정 › "구역 실적·리포트"로 끌 수 있습니다. 디스코드에는 실적·리포트·금리가 하루 4건까지 올라갑니다.

## 도시 (노선도와 장면)

플레이어 쪽:
- 하단 메뉴 **도시** → 지금 있는 역의 **장면 카드**와 채팅. 왼쪽 위 **◎ 노선도**에서 역을 누르고 "이 역으로 가기".
  노선도에는 사람 수, 새 이야기(빨간 점), 가 본 역(속이 찬 점)이 보입니다.
- 채팅: 장소 · 전체 · 귓속말. 마크다운, `/행동` 또는 `*…*`, `/주사위 2d6+1`(봉인, 못 고침), `/귓 이름 할 말`, `[[일터]]` 같은 바로 가기.
- ⚡ › **특기 쓰기**: 특기 페이지와 같은 결제가 되고, 결제 카드가 장면 채팅에 올라갑니다. `/특기 쾌검 5`도 같은 창을 엽니다.
- ☆를 누르면 **명장면**으로 남습니다. 장면 오른쪽 위 ★에서 명장면과 세션 기록(.md 내려받기)을 봅니다.
- ✎에서 모습을 고치고, **초상화**를 직접 올릴 수 있습니다(안 올리면 도트 얼굴).

딜러 화면 › **도시**:
- **장면 콘솔**: 장소를 고르면 그 장면이 미리 보입니다.
  - **이 장소의 배경 › 그림 올리기**: 여러 장 올려 두고 썸네일을 누르면 모두의 화면에 바로 바뀝니다. "기본 그림"으로 되돌릴 수 있습니다.
    ⚙에서 필터(은은하게 · 강하게 · 틀만), 초점(위 · 가운데 · 아래), 이름, 출처, 감각 한 줄을 고칩니다.
  - **효과**: 흔들림·금빛은 한 번, 경보·정전·비·안개는 끌 때까지 계속.
  - **무대 위 NPC**: 이름을 누르면 장면의 사람 줄에 올라가고, 💬를 누르면 채팅에서 그 NPC로 말합니다.
  - 오른쪽 채팅의 **말하는 이**: 서술(가운데 금테 줄) · 딜러 · NPC. `/판정 …`은 판정 카드. ⚡에서 **장면 컷**을 보냅니다.
  - **맞붙기**: 열어 두면 그 장소의 특기 결제가 점수판에 오릅니다. 상대 점수를 걸고, 결과를 적어 "결과 발표하고 닫기".
- **NPC**: "세계관 NPC 만들기"로 13명(이름과 구역만)을 한 번에 만들고, 초상화와 비밀 메모(딜러만)를 붙입니다.
- **장면 컷**: 채팅에 끼워 보낼 그림 보관함.
- **세션·노선**: 세션 열기/닫기(새벽 4시에 저절로 닫힘), 노선 운휴/운행.
- **기록**: 명장면과 세션 로그 내려받기. 귓속말은 딜러가 장면 콘솔 채팅의 귓속말 탭에서 모두 봅니다.

설계와 결정 기록: [SPEC-CITY-MAP.md](./SPEC-CITY-MAP.md).

## 디스코드 알림 켜기 (한 번)

웹훅 주소가 플레이어에게 노출되지 않도록 Cloudflare Worker가 중간에서 보냅니다. 무료입니다.

1. 디스코드 채널 설정 › 연동 › 웹후크 › 새 웹후크 → **웹후크 URL 복사** (채팅에 붙이지 마세요).
2. [Cloudflare](https://dash.cloudflare.com/sign-up) 무료 계정을 만들고, 이 폴더의 터미널에서:
   ```
   corepack pnpm --filter @fortuna/notifier exec wrangler login
   corepack pnpm --filter @fortuna/notifier exec wrangler deploy
   corepack pnpm --filter @fortuna/notifier exec wrangler secret put DISCORD_WEBHOOK_URL
   ```
   마지막 명령에서 웹후크 URL을 붙여 넣습니다. `deploy`가 알려 준 주소(`https://fortuna-notifier.<계정>.workers.dev`)를 복사합니다.
3. 딜러 화면 › 설정 › 디스코드 알림 › **중계 주소**에 붙여 넣고 저장.
4. 어떤 사건을 알릴지 켜고 끕니다. 보내지 못한 알림은 같은 화면에서 다시 보낼 수 있습니다.

웹후크를 바꾸고 싶으면 3번 명령의 `secret put`만 다시 실행하면 됩니다.

## 무료 한도
